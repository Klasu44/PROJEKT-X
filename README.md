# INTERREGNUM

Przeglądarkowa strategia polityczna / gra decyzji osadzona w fikcyjnej Republice Veligradu. Kampania rozpoczyna się 3 stycznia 1994 podczas kryzysu konstytucyjnego.

## Status
**Tura 1/12 — World Foundation: ukończona.**

Powstały: kanon świata, historia 1945–1994, regiony, sąsiedzi, podstawy ustroju i gospodarki, doktryna projektowa oraz pierwszy działający interfejs React/TypeScript.

## Uruchomienie
```bash
npm install
npm run dev
```

Build produkcyjny:
```bash
npm run build
```

Dokumentacja: `docs/WORLD_BIBLE.md` oraz `docs/ROADMAP.md`.
